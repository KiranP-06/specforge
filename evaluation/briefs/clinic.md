# Clinic Appointment System
Patients must be able to register and log in with a phone number and OTP.
Patients can search doctors by speciality and view available slots.
A patient should be able to book an appointment for an available slot.
Patients can cancel an appointment up to 2 hours before the start time.
Doctors can view their daily appointment schedule.
Doctors can add prescription notes to a completed appointment.
The system shall send an SMS reminder 24 hours before each appointment.
Receptionists can reschedule appointments on behalf of patients.
Admins can create, edit and deactivate doctor profiles.
Admins should be able to export monthly appointment statistics as CSV.
Patient medical records must be encrypted at rest and in transit.
The booking page must load within 3 seconds on a 4G connection.
The system should be available 99.9% of the time.
The system must comply with local health-data privacy regulations.
